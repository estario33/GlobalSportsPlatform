# ADR-010: Anti-Corruption Layer для интеграции с магазинными системами

[← Индекс ADR](README.md)

- **Статус:** принято (на утверждение архитектурным комитетом)
- **Дата:** 2026-10-25
- **Этап регламента:** 2

## Контекст
R10: интеграция с существующими приложениями без их переписывания; RSK-05, RSK-19.

## Решение
Commerce Connector изолирует доменную модель приложения от внешних. Содержит адаптеры к каталогу, deep links, атрибуции. Режимы: read-only на фазе 1–2; каталог кэшируется (TTL, ETag), на сбой — деградация (скрыть товары, показать общую рекомендацию). Атрибуция: ссылка с подписанным токеном кампании, возврат события покупки через webhook/пакетный отчёт. Покупка и платёж выполняются в существующих приложениях.

## Рассмотренные альтернативы
- Прямые вызовы из сервисов — жёсткие связи.
- Встроенная корзина — non-goal.

## Последствия
+ независимая эволюция, защита от сбоев.
− зависимость от стабильности API; нужны контракты и SLA с владельцами.
Пересмотр: при появлении единой платформы электронной коммерции.
