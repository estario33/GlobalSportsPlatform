# ADR-008: Приватность по умолчанию, зоны приватности и k-анонимность

[← Индекс ADR](README.md)

- **Статус:** принято (на утверждение архитектурным комитетом)
- **Дата:** 2026-10-25
- **Этап регламента:** 2

## Контекст
Геоданные и данные о здоровье — самый чувствительный класс; дети; поиск людей рядом (R3); сравнение с регионом (R2).

## Решение
(1) Новые профили приватны: данные видны только владельцу, активность — друзьям/группам по выбору. (2) Согласия по целям отдельно (аналитика, маркетинг, поиск людей, геолокация, шаринг), отзыв в один шаг. (3) Зоны приватности: начало и конец маршрута маскируются в радиусе; по умолчанию включено вокруг домашнего адреса. (4) Поиск людей оперирует грубой сеткой (geohash низкой точности) и временными статусами с TTL; точные координаты не покидают ячейку. (5) Любая статистика по группе публикуется при когорте ≥ 50 (k-анонимность), для редких когорт — укрупнение. (6) Для несовершеннолетних — закрытая модель, без поиска, без маркетингового таргетинга.

## Рассмотренные альтернативы
- Настройки «по умолчанию открыто» — высокая эффективность охвата, но неприемлемые юридические и репутационные риски.
- Полный запрет геопоиска — не позволяет выполнить R3.

## Последствия
+ защита, доверие (BG-4).
− ниже начальная вирулентность и доступный объём данных для таргетинга; требует метрик согласий.
Пересмотр: ежегодный по итогам аудита DPO.
