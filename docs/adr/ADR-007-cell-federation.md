# ADR-007: Федерация между ячейками: минимальный контракт

[← Индекс ADR](README.md)

- **Статус:** принято (на утверждение архитектурным комитетом)
- **Дата:** 2026-10-25
- **Этап регламента:** 2

## Контекст
Друзья и группы могут объединять пользователей разных регионов; путешественники тренируются вне домашнего региона (O1). Резидентность (ADR-002) ограничивает обмен.

## Решение
Между ячейками передаётся только: псевдоним, публичный профиль (имя, аватар, виды спорта), запросы дружбы и приглашения, событие «достижение» в виде карточки без трека и точных координат (только с согласия автора), результаты соревнований. Доступ — через федеративный API с подписанными токенами и записью в аудит. Чужие ячейки не читают БД друг друга. Данные путешественника принимаются edge-приёмником ближайшей ячейки и пересылаются в домашнюю (буфер на устройстве при отсутствии связи). Группа принадлежит ячейке создателя; участники из других ячеек видят её через федеративный API.

## Рассмотренные альтернативы
- Репликация всех социальных данных между ячейками — нарушает резидентность.
- Запрет межрегиональных связей — ломает BG-1.

## Последствия
+ сообщества глобальные, данные локальные.
− дополнительная задержка межячеечных запросов, сложнее отказоустойчивость; нужны контрактные тесты федерации.
Пересмотр: после пилота второй ячейки.
