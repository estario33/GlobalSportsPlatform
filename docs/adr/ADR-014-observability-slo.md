# ADR-014: Наблюдаемость и SLO

[← Индекс ADR](README.md)

- **Статус:** принято (на утверждение архитектурным комитетом)
- **Дата:** 2026-10-25
- **Этап регламента:** 2

## Контекст
Основной обеспечивающий атрибут для QA-1 и QA-2; многоязычные команды; ячейки на разных провайдерах.

## Решение
Стандарт OpenTelemetry для метрик, трассировок и логов; сбор в региональные бэкенды ячейки; глобальные дашборды получают только метрики без PII. SLO для SC-1…SC-7 с error budget и алёртами по burn rate. Логи структурированные, без PII, с псевдонимом пользователя. Обязательные сигналы: RED на сервисах, лаг шины, глубина клиентских очередей (по телеметрии клиента), стоимость по тегам. Синтетические проверки из ключевых регионов; game days перед фазой 3.

## Рассмотренные альтернативы
- Инструменты провайдеров — несовместимые данные между ячейками.
- Минимальный мониторинг — не позволяет соблюдать SLO.

## Последствия
+ единая картина по всем ячейкам, раннее обнаружение.
− стоимость хранения телеметрии; дисциплина тегирования.
Пересмотр: при росте затрат на наблюдаемость > 10% стоимости ячейки.
