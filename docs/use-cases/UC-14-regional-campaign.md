# UC-14. Региональная кампания маркетолога

[← Индекс](README.md)

- **Актор:** региональный маркетолог, глобальный бренд-менеджер. **Цели:** BG-2; FR-PM-02, FR-AD-01. **ADR:** 011.
- **Основной поток:** выбор шаблона → настройка региона, языка, аудитории, расписания, лимитов → предпросмотр → согласование (бренд-менеджер при отклонениях) → публикация в ячейки региона без релиза → отчёты (агрегаты без PII).
- **Альтернативы:** несоответствие глобальным ограничениям — отклонение; ошибка в кампании — отключение одним действием.
- **Критерии:** публикация ≤ 1 дня, откат ≤ 5 минут.
