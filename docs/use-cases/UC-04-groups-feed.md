# UC-04. Вступление в группу и работа с лентой

[← Индекс](README.md)

- **Актор:** пользователь, организатор группы, модератор. **Цели:** BG-1; FR-SC-01…06; SC-3. **ADR:** 007, 008.
- **Основной поток:** поиск/рекомендации групп → вступление (открытая — сразу, по заявке — одобрение) → лента (тренировки участников, достижения, комментарии) → реакции и комментарии.
- **Альтернативы:** закрытая группа — только по приглашению; жалоба на контент — очередь модерации; участник из другой ячейки — через федеративный API.
- **Правила приватности:** в ленту попадает только то, что автор разрешил для этой группы; точный трек не публикуется без явного согласия.
- **Критерии:** p95 ленты < 500 мс; жалоба обрабатывается ≤ 24 ч; блокировка действует мгновенно.
