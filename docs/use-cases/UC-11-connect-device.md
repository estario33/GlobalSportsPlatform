# UC-11. Подключение устройства

[← Индекс](README.md)

- **Актор:** пользователь. **Цели:** BG-3; FR-DV-01…03, FR-AR-03.
- **Основной поток:** выбор типа устройства → разрешения → BLE-сопряжение (стандартный HR-профиль) или OAuth к облаку производителя → тест чтения → устройство добавлено в профиль → данные включаются в тренировки.
- **Альтернативы:** профиль устройства нестандартный — используется коннектор из справочника (ADR-001, NFR-MOD-01); токен облака отозван — повторная авторизация.
- **Критерии:** подключение ≤ 60 с; ошибки коннектора не нарушают запись.
