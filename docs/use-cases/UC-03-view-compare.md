# UC-03. Просмотр результата и сравнение с собой, регионом, профи

[← Индекс](README.md)

- **Актор:** пользователь. **Цели:** BG-3; FR-AN-01…04; SC-2. **ADR:** 004, 008.
- **Основной поток:** открыть тренировку → сводка (дистанция, темп, пульс, зоны) → блок «Ты vs ты»: сравнение с последними 4 неделями, личные рекорды, тренд → (опционально) перцентиль в регионе → (опционально, фаза 3) профиль профессионала как референс.
- **Альтернативы:** когорта < 50 — укрупнение или скрытие блока; метрики ещё считаются — показывается «обрабатывается» с автообновлением.
- **Данные:** оперативные метрики из Activity; агрегаты региона — из Analytics (обновление раз в сутки).
- **Критерии:** p95 открытия < 1 с (кэш); перцентили только по k ≥ 50.
