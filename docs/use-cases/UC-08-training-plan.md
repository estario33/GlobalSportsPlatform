# UC-08. Составление и ведение плана тренировок

[← Индекс](README.md)

- **Актор:** пользователь. **Цели:** BG-3; FR-PL-01…03.
- **Основной поток:** выбор цели и уровня → доступные дни → генерация плана по правилам и шаблонам → календарь и напоминания → после тренировки сопоставление с планом → корректировка нагрузки.
- **Альтернативы:** пропуск тренировок — предложение перенести; смена обуви/инвентаря — подсказка в плане; травма — пауза плана (без медицинских советов).
- **Критерии:** план строится ≤ 5 с; переносы синхронизируются с календарём телефона.
