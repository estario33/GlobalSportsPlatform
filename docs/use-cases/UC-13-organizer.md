# UC-13. Организатор создаёт группу-событие или соревнование

[← Индекс](README.md)

- **Актор:** организатор (пользователь с ролью), модератор. **Цели:** BG-1; FR-SC-03, FR-AD-03.
- **Основной поток:** создание события (маршрут, время, лимит) → правила и приз → публикация → мониторинг регистрации → предпрогрев нагрузки для крупных событий (заявка на платформу за 14 дней) → проведение → протокол.
- **Альтернативы:** событие крупнее лимита — согласование с платформой; нарушение правил — модерация.
- **Критерии:** заявка на масштаб ≥ 100 тыс. обрабатывается заблаговременно (процесс, не автоматизм).
