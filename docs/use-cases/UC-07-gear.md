# UC-07. Инвентарь и своевременная замена обуви

[← Индекс](README.md)

- **Актор:** пользователь. **Цели:** BG-2; FR-GR-01…03, FR-AN-05; SC-6.
- **Основной поток:** добавление пары (каталог/штрих-код) → тренировки автоматически привязываются к паре по правилам (вид спорта) → накопление пробега → порог (например 80% ресурса) → `GearWearThreshold` → Promo подбирает предложение (если есть согласие «маркетинг») → уведомление → переход в магазинное приложение (UC-10).
- **Альтернативы:** нет согласия на маркетинг — нейтральное напоминание без товаров; товар не найден в каталоге — ручной ввод.
- **Критерии:** пробег считается ≤ 1 мин после тренировки; рекомендация не повторяется чаще 1 раза в 14 дней.
