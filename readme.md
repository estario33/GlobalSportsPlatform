## Краткое резюме решения (для чтения за 1 минуту)

- **Продукт:** мобильное приложение-«спутник» тренировки: запись, сравнение с собой, группы по интересам, соревнования, рекомендации по инвентарю и покупкам через уже существующие приложения компании.
- **4 бизнес-цели:** лояльность бренда через сообщества → продажи и информирование о новинках → вовлечённость и удержание → глобальный охват при высоком доверии к данным.
- **3 основных атрибута качества:** безопасность и приватность данных; масштабируемость/эластичность (глобальный рост, пики соревнований); модифицируемость (устройства, виды спорта, региональные промо).
- **Архитектура:** укрупнённые доменные сервисы + событийная шина; **региональные ячейки (cells)** с «домашним регионом» пользователя для соблюдения резидентности данных; offline-first клиент; облачно-нейтральная платформа (Kubernetes + переносимые примитивы), провайдер выбирается на ячейку.
- **Что сознательно не делаем в первой версии:** свободный чат, собственные носимые устройства, сложный ML, живые карты «кто рядом» без явного согласия — см. [план](docs/06-roadmap.md).
